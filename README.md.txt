# AI Contract Analysis using IBM Granite

## Overview
AI-powered contract analysis system using IBM Granite LLM and IBM watsonx.

## Features
- PDF Contract Analysis
- Risk Identification
- Clause Extraction
- AI-generated Insights
- Contract Summarization

## Technologies Used
- Python
- IBM watsonx
- Granite LLM
- LangChain
- Docling

## Project Workflow
1. Upload contract PDF
2. Extract text
3. Process using Granite LLM
4. Generate risk analysis and summary

## Future Improvements
- Web interface
- Multi-document support
- Real-time contract review
